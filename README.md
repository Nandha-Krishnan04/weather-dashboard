🌦️ Weather Dashboard

A responsive Weather Dashboard built using HTML and JavaScript that retrieves real-time weather information for cities around the world using the Open-Meteo public API.

✨ Features

🔍 City Search: Search for weather information by city name.

🌡️ Current Temperature: View the current temperature in Celsius.

🌤️ Weather Conditions: Display weather conditions with emojis.

💧 Humidity: Check the current relative humidity.

🌬️ Wind Speed: View the current wind speed in km/h.

🌡️ Feels-Like Temperature: See the apparent temperature.

⏳ Loading State: Display a loading message while fetching data.

⚠️ Error Handling: Handle invalid city names and API request failures.



🛠️ Technologies Used

HTML5 — Page structure and content.

JavaScript (ES6+) — API integration and dynamic content updates.

Fetch API — Retrieving weather data from external APIs.

Async/Await — Handling asynchronous requests.

Open-Meteo API — Weather forecasts and geocoding.
